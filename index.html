Voice Controls Cheat Sheet

Basic Playback

"Play" / "Resume" - Starts playback

"Pause" / "Stop" - Pauses track

"Next" / "Skip" - Plays next track

"Previous" / "Back" - Plays previous track

Direct Track Search

"Play [Song Name]" - Fuzzy matches and plays specific local file

Example: "Play Moonlight", "Play Jazz Track"

Volume Controls

"Volume Up" / "Volume Down" - Adjusts level by 15%

"Mute" / "Unmute" - Toggles sound

Playback Modes

"Shuffle" - Toggles shuffle mode

"Repeat" - Toggles repeat track mode

Offline Speech Recognition Note:

Modern Chromium-based browsers (Chrome, Edge) support speech recognition using locally cached browser speech models. For true offline speech, ensure browser speech models are permitted or cached by launching speech input while online once.
